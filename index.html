TikTok Auto Poster

This website provides information about the TikTok Auto Poster desktop application.

The application is intended to help creators prepare videos and, when supported and authorized, send videos to TikTok through TikTok's official APIs. Users should only publish content they own or are authorized to share and must review and confirm each post before it is sent.
